# GoogieHost Web Hosting Review Directory

A responsive white-and-blue hosting review directory demo built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete responsive page, search, category filters, review cards, testing methodology and FAQs.
- `render.yaml` — Render Static Site deployment configuration.

## Run locally
Open `index.html` in a browser.

## Deploy to Render
1. Connect this repository to Render.
2. Create a **Static Site**.
3. Use the repository root as the publish directory.
4. Deploy.

The page is a standalone demo. Before production use, verify every provider URL, score, review date and claim against the current GoogieHost review pages. Keep individual review pages as the source of truth for measured results.

## SEO
The page includes a descriptive title, meta description, canonical URL, Open Graph metadata, semantic headings, descriptive internal anchors and crawlable HTML links. Add structured data only when all ratings and review details shown on the page are accurate and eligible.
