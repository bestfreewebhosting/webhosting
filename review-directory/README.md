# GoogieHost Web Hosting Reviews Directory

A responsive, white-and-blue static landing page for a web hosting review directory.

## Files
- `index.html` — complete page with inline CSS and JavaScript (search + category filters).

## Deploy on Render
1. Create a **Static Site** in Render and connect this repository.
2. Set **Root Directory** to `review-directory`.
3. Leave **Build Command** empty.
4. Set **Publish Directory** to `.`.
5. Deploy.

## Before production use
- Confirm all provider URLs and editorial claims before publishing.
- Keep ratings, test dates, scores and review update labels synced with the live GoogieHost review pages.
- Add new providers only when their destination review URL is verified.
- The canonical URL currently points to the main GoogieHost review directory. Change it if this demo is deployed on a different public URL.
